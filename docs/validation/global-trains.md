# 全图抽象车厢同步验证

2026-10-21，Codex。MC 1.21.1 / MTR 4.1.0-beta.2；mod 版本保持 **1.5.2**，静态协议 **v8**，独立车辆协议 **v1**。本报告对应所在提交的功能源码。

## 实现内容

- ServerTrainStream 在服务端事件维护查看维度的全网订阅、1秒续租/5秒租约。每个 Simulator 同时最多一个采集/编码任务，初始目标4Hz；通过 Simulator.run 读取全部 Siding.iterateVehicles，不使用玩家距离/视口筛选。
- CoreTrainAdapter 只读取 TSC 原生车厢位置。双 bogie 分别取中点，单 bogie 保留两个方向采样；两点 XYZ 相对 float 为24B/节，另每列 double XYZ 原点24B。保留原生方向、尺寸和参考点 XYZ，不传倾角、不复制行车/信号逻辑、不强制加载区块。
- 相同编组/服务定义共享内容 ID，仅首次/变化时发送；高频位置帧没有文字、模型、尺寸或逐车厢维度。定义字段组合在一个不可变 Definition，而非分别建立两条协议流。
- 原子完整帧、分片长度/数量/重复校验、16MiB大小边界、未知定义整帧拒绝、错代/错维度/错流拒绝、关闭/切服清理。成功完整集合才删除缺失车辆，单车无法定位保留身份及计数。
- 有界后台编解码；服务端每连接2MiB/s正文预算、每tick最多2片、全局每tick4MiB发送预算。旧待发完整帧合并，正在发送的逻辑帧必须发完；预算不足降低整网实际刷新频率，不退成附近/视口子集。源样本年龄随片发送，客户端能显示刷新减慢/过期。
- 客户端两个实测帧间插值，无速度积分、路径求解或外推。以实际采样间隔作为插值窗口，通常约250ms；反向、定义替换、时间重置及大位移断点直接切换。按视野筛选可见符号，缩远不为隐藏尾车分配四角；静止时复用绘制结果，动态帧不重建静态轨道缓存。
- Xaero/JourneyMap 共享控制器、数据和悬停样式。默认显示车型资源名称（缺资源回退 Train）、可用线路/终点和节数；不猜原生缺失元数据。距离/ETA仍暂停。
- Xaero 原本会暂停集成服务器，实测导致首帧一直加载。新增仅在启用实时车辆层时取消 Xaero 的单机暂停；菜单和关闭车辆层的正常暂停行为保留。专用服务器不加载此客户端 mixin。

新增13项测试包括：

- 独立真实 TSC Simulator、200000格远处的停放车辆、单/双及非对称 bogie、原生坐标对照、稳定身份和撤销。测试只在临时文件夹创建状态，无 Minecraft 客户端/实体/玩家；用源代码已知的私有车辆表注入测试夹具，生产代码只用公开遍历API。

- 1000列×8节的完整位置帧编码长度为 **220899B**，4Hz等价 **883596B/s** 应用正文；不含分片信封、首次定义、TCP及连接压缩，不是实测服务器带宽或FPS。旧128B/节数值基线为4096000B/s，只有计费内容相同的坐标项可作精确百分比比较。

## NeoForge 游戏内验证

使用独立副本 `run/saves/GlobalTrainSyncTest`，原有 TestWorld 不修改。运行命令：`gradlew runClient -Pquickplay=GlobalTrainSyncTest --no-daemon`。用 MTR 原生命令 `/mtr instantDeploy allDepots` 部署列车，运行由 TSC 推进。

1. JourneyMap 显示全网1列/3节，观察列车由直线进入弯道；悬停显示车型后备名称、Local→Charlie及3节信息。
2. 玩家传送至 `(2000.5, -59, 2000.5)`，远离线路（约X=0..600、Z=0..80）。只把地图定位到 `(300,0)`，玩家仍留远处。JourneyMap 全图计数持续为1。
3. 修复暂停行为后重启客户端，Xaero 首帧正常完成，缩远完整网标记、放大3×查看全部三节车厢及过弯，悬停命中中间车厢。此时 MTR 原生客户端附近集合为0，不能由附近回退解释显示结果。
4. 同一次 Xaero 会话，日志中的首节锚点持续变化（节选）：

```text

          first XYZ=331.28613453029493/-59.0/37.48262208981933
20:00:52  Global trains: 1 trains, 3 cars, 0 unlocatable, 125 bytes/frame; native nearby=0
          first XYZ=358.01484566972925/-59.0/5.706754440569117
20:01:49  Global trains: 1 trains, 3 cars, 0 unlocatable, 125 bytes/frame; native nearby=0
```

125B 为一列三节完整位置正文（24B时间、计数/紧凑身份/方向、24B原点、72B坐标）；不能把它当成TCP实际字节。地图开关切换、两宿主重新订阅经过实测，没有叠画附近车辆。原生当前线路为空的时段以“—”显示，未从静态颜色推测线路。

## 尚未实测的边界

- 1000/5000列真实运营网络的服务端采集、多人总出站、分配率/GC和游戏帧时间；本次仅测协议大小及单列游戏场景，不能宣称大网性能已验证。
- 高速最小半径的屏幕插值误差、跨维度游戏内切换、恶劣网络、Simulator在线替换和Fabric游戏内运行。状态机/边界有实现和部分单测，仍需相应运行场景。
- 原生 getVehicleCarsAndPositions 仍计算完整 bogie 中间数据；简化主要减少网络和客户端工作。为排除明显占位，采集另查原生head并校验距离，不是零服务端开销，也不是所有损坏路径的形式化有效性证明。
- 只画抽象刚性2D符号；不保证原生3D角点/坡度/侧倾。离散点插值可能切弯，无后帧时冻结，不做客户端轨道模拟。

测试包目录：`../test-builds/v1.5.2-global-trains`，包含NeoForge/Fabric两个JAR和校验值；服务器和客户端需一起更新，版本号仍1.5.2。
