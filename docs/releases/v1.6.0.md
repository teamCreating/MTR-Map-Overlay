Compared with v1.5.3, this release adds optional HowToGo destination handoff, per-station Navigate availability, and complete four-language interface resources.

### Added

- **HowToGo integration.** With a compatible HowToGo build installed, select it from a station's Navigate action to hand off the station's actual name and block coordinates. HowToGo owns route search, travel preferences and guidance; it remains optional.
- **Availability-aware Navigate.** The action is dimmed when no provider can handle the selected station. Available providers appear in the chooser, with availability checked again on click. Existing three-argument provider registrations remain compatible; a new optional predicate overload supports per-target readiness.
- **Four interface languages.** English, Simplified Chinese, Traditional Chinese and Japanese cover map controls, station arrival boards, tooltips, commands and diagnostic feedback, following the game language. Player-defined station and route names remain unchanged.

### Fixed and improved

- Forge1.20.4 quick-play now completes native loading before connecting a world, preventing missed server lifecycle initialization and Xaero disconnects while preserving loading warnings and errors.

- Translated Xaero controls render text separately from their icons. JourneyMap toolbar labels, PIDS style names and older tooltip/command messages are localized.
- Closed, stale or failing navigation providers cannot be invoked; provider errors do not disable other providers or flood the log.
- Diagnostic marker results use explicit success values rather than parsing English text, including failures while JourneyMap is not ready.
- Native arrival boards, independent map focus/dimming, whole-map trains and pure 2D rendering remain available on all supported builds.

### Supported builds

- Minecraft **1.21.1**: **NeoForge / Fabric**, **MTR 4.1.0-beta.2**, Java 21.
- Minecraft **1.20.1 / 1.20.4**: **Forge / Fabric**, **MTR 4.0.5**, Java 17.
- Choose the exact Minecraft/loader attachment. Station arrivals and full-network data require server-side Overlay support; install matching builds on both sides.

### 中文更新说明

相较 v1.5.3，本版新增可选 HowToGo 目的地转交、逐站 Navigate 可用性检查及完整四语言界面。

**新增功能**

- **HowToGo 对接**：安装兼容版本后，可从车站 Navigate 入口选择 HowToGo，转交真实站名与方块坐标。路径搜索、出行偏好及引导由 HowToGo 负责，仍为可选依赖。
- **导航可用性检查**：没有可用于当前车站的服务时按钮淡显；多个可用服务显示选择器，点击时再次验证。保留原有三参数注册接口，并新增逐目标可用性判定。
- **四语言界面**：英文、简体中文、繁体中文与日语覆盖地图控件、站点到发板、提示、命令与诊断反馈，跟随游戏语言。玩家自定义站名、线路名保持原样。

**优化与修复**

- 修复Forge1.20.4快速进入存档时的加载顺序，保留原生警告与错误页面，避免漏发服务端生命周期事件导致Xaero初始化失败和断线。

- Xaero 控件将文字与图标分离绘制，补全 JourneyMap 工具栏、PIDS 样式名及旧提示、命令的翻译。
- 关闭、过期或异常的导航服务不会被调用，也不会影响其他服务或反复刷日志。
- 测试标记改用明确的成功状态，不再解析英文消息；JourneyMap 尚未就绪时正确反馈失败。
- 保留六平台的原生到站板、独立聚焦与淡化、全图列车及纯二维绘制。

MC 1.21.1 对应 NeoForge/Fabric、MTR 4.1.0-beta.2 与 Java 21；MC 1.20.1／1.20.4 对应 Forge/Fabric、MTR 4.0.5 与 Java 17。请按精确 MC/加载器选择附件；全网与站点预测需服务端支持。
