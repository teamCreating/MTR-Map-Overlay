Compared with v1.5.2, this release adds native station arrival boards, British and European PIDS styles, and a unified map-view API for third-party navigation mods across all six supported builds.

### Added

- **Pinned station information and native arrivals.** Click a station to keep its original station, platform and route information open. The card starts collapsed; **Expand** shows the next available services by destination, line and platform. Predictions come directly from the MTR/TSC data interface used for PIDS, with missing predictions shown explicitly.
- **British and European/airport PIDS styles.** British black/amber is the default. `/mtrmap config pidsStyle british|european` switches the style immediately and saves the choice; omit the style argument to query the current setting.
- **A unified navigation and display API.** External mods can read native stations, routes, stops and path sections, subscribe to arrival boards, and control independent map views. Upcoming sections can remain bright while completed sections and unused lines are dimmed separately. The **Navigate** entry supports registered providers and a chooser when several are available; third-party mods supply the navigation integration.
- **The same features on all six platforms.** NeoForge/Fabric MC 1.21.1 builds target MTR 4.1.0-beta.2; Forge/Fabric MC 1.20.1 and 1.20.4 builds target MTR 4.0.5. Native station arrivals require matching client and server Overlay versions.

### Optimized and fixed

- Shared native arrival collection and encoding on the server, with subscriptions released when boards are collapsed or closed. Bounded queues, paced chunks and fair scheduling reduce repeated work and prevent large catalogues from monopolizing updates. Clients decode snapshots in the background without running another transit simulation.
- Preserved the classic station card and Xaero ROUTES/TRACKS controls. Improved narrow-window summaries, long-text hover details, PIDS column alignment and ETA readability; panel clicks and scrolling no longer trigger map pan or zoom.
- Fixed tracks and the player arrow appearing over station panels. Retained loader-specific Forge 47/49 networking and input handling, plus JourneyMap 5/6 rendering bridges.
- Applied navigation dimming consistently to route colours, high-speed white blocks, soft edges and rail backing. Upcoming sections remain bright when a later navigation leg reuses the same track. Whole-map trains and pure 2D rendering remain available.

### 中文更新说明

相较 v1.5.2，本版新增原生站点到站板、英式与欧式 PIDS，以及供第三方导航模组接入的统一地图显示 API，六个平台同步提供。

**新增功能**

- **站点点击固定与原生到站预测**：保留原站点、站台和线路信息，默认折叠；点击 **Expand** 后按目的地、线路和站台显示下一班可用服务。直接使用 MTR/TSC 给 PIDS 的数据接口，无预测时明确显示缺失。
- **两种 PIDS 样式**：默认英式黑底琥珀字，另提供欧式/机场风格。`/mtrmap config pidsStyle british|european` 可即时切换并保存，省略样式参数可查询当前设置。
- **统一导航与显示接口**：第三方可读取原生站点、线路、停站和路径区段，订阅到站板并控制独立地图视图。待乘区段保持明亮，已走区段和未用线路可分别变暗。**Navigate** 入口支持注册导航服务及多个服务间选择，具体导航由第三方模组接入。
- **六平台功能同步**：MC 1.21.1 的 NeoForge/Fabric 包对应 MTR 4.1.0-beta.2；MC 1.20.1／1.20.4 的 Forge/Fabric 包对应 MTR 4.0.5。原生站点预测需客户端和服务端安装匹配版本。

**优化与修复**

- 服务端共享原生预测采集和编码，折叠或关闭到站板后释放订阅；通过队列限额、分片节流和公平调度减少重复工作，避免大型目录独占更新。客户端后台解码，不维护第二套行车模拟。
- 保留旧式站点信息框与 Xaero ROUTES/TRACKS 控件；改善小窗口摘要、长文本悬停、PIDS 列对齐和 ETA 显示，防止面板点击、滚动误触地图拖动或缩放。
- 修复轨道和玩家箭头覆盖站点面板的问题，保留 Forge 47/49 的网络与输入处理，以及 JourneyMap 5／6 绘制适配。
- 导航 dimmed 同时作用于线路色、高铁白块、柔化边缘和轨道底衬；后续乘车区段重复使用同一轨道时保持明亮。继续保留全图列车和纯 2D 绘制。
