## 2. 界面结构与视觉方向

沿用Minecraft字体、紧凑深色面板、清晰边框和现有站点/车厢符号。线路颜色只用作辅助识别，开关另有勾选、文本和焦点框。保持地图为主要内容，不自动改变线路世界宽度、车厢LOD或缩放手感。

设计四个各司其职的区域：

1. **地图入口**：Xaero默认一个带文字的“MTR”紧凑按钮；JM复用宿主addon入口。打开同一份图层菜单，不再常驻两块英文大按钮。
2. **图层菜单**：总开关、线路、轨道、列车、站点；“更多显示选项”内放站台、车厂、空站、隐藏线路说明、布局与同步详情。两个地图共用设置语义，不强行统一宿主按钮位置。
3. **站点面板**：选中站的固定到站板，有标题、收起、关闭和独立滚动区；默认不展开、不查询ETA。
4. **状态提示**：一个紧凑状态条/图标，正常状态可收起；有延迟/仅附近/能力缺失时保留简短说明。展开可分别查看线路数据、车辆流和本站ETA状态。

概念线框，仅表达分区，不代表已渲染效果。图层菜单和站点卡片共用侧边区域，菜单打开时临时覆盖卡片绘制而不取消其选择；这种短暂弹层不改变ETA兴趣，关闭即回到原卡片。

```text
┌─ 宿主地图控件保留 ────────────────────────────────┐
│ [MTR ▾]                         宿主地图控件     │
│ ┌ Central ───────── [收起] [×] ┐                 │
│ │ ● 绿色线                                      │
│ │ → Airport · 2站台       2分15秒                │
│ │ → Harbour · 1站台       已到站                 │
│ │ ▣ 红色线                                      │
│ │ → North · 4站台         暂无可用预测           │
│ │ 数据覆盖不全 · 部分班次可能未返回              │
│ └──────────────────────────────┘                │
│                   地图：线路/站点/车辆           │
│ [MTR · 全图列车] [当前聚焦：某扩展 · 暂时看全图] │
└─────────────────────────────────────────────────┘
```

所有尺寸使用GUI逻辑像素，初始建议按钮高20–24、内边距6、站点面板宽220–300；只是实施起点，须实机检查中文长名/GUI scale后确定。不要将物理屏幕像素和GUI像素混用。

## 3. 布局、缩放与可达性

- 宿主适配器提供可用区域、已知控件占区、投影及输入能力；布局按屏幕边缘停靠，边距至少6 GUIpx。JM优先原生addon按钮，卡片避开其右侧控件；Xaero避免继续假定(5,60)永远安全。
- 若宿主无法提供可靠占区，不宣称能自动识别所有第三方UI。提供左右停靠/紧凑模式，记住每种宿主的本地偏好；调整屏幕/GUI scale后重新钳制面板位置，不允许漂到屏幕外。
- 可用侧栏宽度不足约200时改为底部卡片，最多占可用高度约45%；连标题和一行内容都容不下时使用紧凑标题+“详情”页。门槛均为待验证建议，极小窗口也必须可关闭/返回。
- 不因展开卡片自动平移或放大地图。可另提供一次性的“定位此站”，仅在当前宿主已验证center操作时启用；不持续锁定镜头、不新增跟车。
- 卡片内内容滚动，标题/关闭保持可见；列表只布局/绘制可见行。长线路名/终点允许最多两行后省略，完整文本以提示/详情查看；保留MTR多语言名称语义，不按逗号切description重新建线路关系。
- 三语言en_us/zh_cn/zh_tw同步；不再将英文单词烘焙进按钮PNG。原生MC字体渲染可翻译文本，图标资源只表达图形；用户数据站名不机器翻译。
- 开关、关闭、收起和列表项可Tab/Shift+Tab聚焦，Enter/Space激活，焦点进入可滚动区后方向键/PageUp/PageDown滚动；提供原生叙述标签。未聚焦本UI时不截获宿主方向键。
- 颜色相近线路仍靠名称/编号区分；“实时/计划、过期、覆盖不全”必须有文字，不只改颜色。避免常驻闪烁/呼吸动画和自动滚动跑马灯。

## 4. 输入与悬停规则

宿主弹窗/输入框优先，不能只因当前screen属于地图就抢输入。Overlay内部顺序为：菜单/候选列表→固定面板→可见标记/车辆→线路→空白地图。绘制、命中、scissor必须使用同一布局结果。

| 动作 | 行为 |
| --- | --- |
| 左击MTR入口 | 打开/收起图层菜单，菜单内点击不平移地图 |
| 左击站点 | 按住/释放位移≤建议4 GUIpx且同一有效目标时固定展开；超过阈值让地图继续正常拖动 |
| 左击同站/另一站 | 同站聚焦不重订阅；另一站替换，不让旧响应覆盖 |
| 滚轮位于面板 | 只滚动面板；到列表边缘也不穿透缩放地图 |
| 滚轮位于地图 | 完全保留宿主缩放行为 |
| 拖动从地图开始 | 即使穿过面板也不半途抢走；面板内按下则捕获到释放，避免拖出后误操作地图 |
| Esc | 先关Overlay最上层弹层，再关固定站点卡，再交回地图；设置详情页先返回原页面。宿主已有弹窗时服从宿主 |
| 右键/双击 | 保留宿主菜单/路标语义，1.5.3不添加Overlay右键手势；同一次手势只触发一次逻辑动作 |

站点按下不能直接取消全部地图输入后又声称可无缝拖动：输入桥必须验证“可延迟识别点击且宿主仍能拖动”的实际顺序。如果宿主marker点击API无法满足，使用经验证的screen按下/释放桥；不猜测事件时机。JM的150ms旧防重复机制不能掩盖丢失的合法键盘激活。

参考MTR MapComponent的释放时判定，但使用整个手势最大位移/拖动标志：一旦超过阈值，即使拖回按下点释放也不能触发站点点击。候选弹窗可临时随指针关闭，固定站点卡片不采用MTR鼠标移开即关的行为。

悬停只显示一张Overlay简要提示：优先UI控件，地图对象提示在菜单/面板区域内停止。站点提示只给站名、少量线路及“点击查看到站”；固定面板已选同站时不重复显示同份提示。列车维持车型、线路/终点、节数；缺字段用“—”，不做时间/距离推测。

拾取以屏幕GUIpx容差为准，再换算世界查询范围；只查当前真正可见、未被区段过滤/裁掉的元素。站点/站台密集重叠时生成有界候选列表，提示存在多个目标，点击选择而非永远命中第一项；同一候选结果用于hover和click，不靠名称/颜色合并。列车仍只有悬停，不新增点击详情功能；与站点重叠时hover候选保留两类身份，按屏幕距离/可见绘制顺序确定首项，站点列表入口仍可到达。

线路提示只在没有点对象候选时查询，并复用当前LOD的可见曲线/区段命中，不继续使用粗采样折线或每帧全网扫描。候选上限/截断明确显示“放大以选择”，不把被截断对象计成完整列表。

JM必须明确单一tooltip所有者：首选用共享命中与提示接管Overlay自己的marker标题；只有已验证共享hover/输入桥后才抑制原生标题，不能先清空title导致无提示。宿主路标/其他模组overlay的提示仍由宿主管理。桥不可用时保留静态原生提示并标明到站交互暂不可用，不接管整个地图。

## 5. 站点卡片、数据状态与外部聚焦

站点卡片沿用主计划NONE/PINNED_COLLAPSED/PINNED_EXPANDED状态机。每条线路标题下保留目的地/方向/站台子行；ETA变化不重新按最短时间排序整张表，避免指针下项目跳动。线路/服务组以稳定ID排序，结构变化才更新行位置，局部ETA文字至少按秒更新即可。

同站数据刷新保留用户展开状态、滚动锚点和焦点；使用原生ID/服务组键，不能直接沿用MTR管理列表的颜色/名称分组。站点首次展开后各线路ETA默认可见，不能再默认折叠所有线路让用户逐条点击；方向/站台过多时允许主动收起分组。

- 加载中：“正在获取到站信息…”；不先显示0秒或“无车”。
- LIMITED：“数据覆盖不全”，保留已返回班次，各缺组标“暂无可用预测”。
- STALE：“上次更新…前”，冻结/灰显最后已知状态；不无限倒计时至负数。
- UNSUPPORTED：“服务端未提供本站到站信息”；可解释原生同维度附近回退，但不让“重试”伪装能解锁能力。
- 有效空结果、站已删除、离线等分别提示；“重试”只能走既有限频请求，不触发整网刷新或绕过服务器额度。

状态条把**静态线路覆盖、动态车辆覆盖、本站ETA**分开：全图线路不代表全图车辆；零辆但成功收到完整帧是有效空网，不能显示加载中。用户关闭networkSync时写“已关闭全网同步 · 使用附近数据”，区别“服务端未提供全图车辆”；原数据层尚不能证明的原因标未知。技术字段/错误详情收在展开区，不常驻占地图。

外部FOCUS有效时显示“当前聚焦：扩展名称”，仅接收有长度限制的纯文本显示名，回退owner ID。提供“暂时看全图/返回聚焦”作为本地查看覆盖，保留第三方句柄和导航状态；不调用对方取消导航、不改MTR数据。最新外部replace不能悄悄取消用户的暂时全图选择；本地覆盖持续到用户恢复或换世界。无可靠显示名时也不反射第三方取名。图层总开关继续优先。

## 6. 内部结构与生命周期

拟新增共享`OverlayUiController`（选择/焦点/弹层/输入）、`OverlayUiLayout`（矩形/裁剪/占区）、`OverlayUiModel`（显示数据/文案状态）和两类host bridge。名称为内部设计，不纳入公共API v1；UI不能直接读TSC对象或让公共API依赖GuiGraphics。

设置写入统一适配服务：保持现有配置键，区别持久显示偏好与临时面板/导航状态。Fabric当前set会同步保存文件，多项设置按一次用户操作批量保存；命令/菜单/宿主按钮走同一更新通知。NeoForge持久化语义按实际API核对，不直接假定set已写盘。界面显示选项只改本机偏好，不改服务器设置。

地图内设置优先用同屏弹层，避免为了开菜单替换screen实例而丢车辆兴趣。若必要进入详情Screen，保存父screen和恢复策略，明确期间不绘制地图/暂停Overlay实时兴趣；不引入整套新UI框架或强制Cloth/ModMenu依赖。Overlay所有控件关闭时仍留下可重新启用的入口，但不能保留隐藏可点击区域。

实时兴趣由已验证的地图上下文决定：需要动态列车或已展开站点ETA，才在集成服允许实时推进；车辆开关关闭不应使ETA停住。只对实际地图上下文生效，普通暂停菜单、离开地图和不需要实时数据的设置详情不得自动取消暂停。暂停/子界面下ETA标“暂停”或停止兴趣，不能将不变预测装成实时。JM5/6也要验证实际暂停行为，不因Xaero已有mixin就假定其他地图正确。

关闭地图释放内置卡片兴趣、指针捕获、hover和布局引用；切服/世界epoch变化清空选择和未完成回调。拓扑更新保留相同有效stationId的卡片，站删除则显示已删除并释放查询。地标重建不能仅因MarkerOverlay实例变化清空选择。导航会话及用户暂时全图覆盖与内置卡片生命周期分离。

## 7. 开销与实施验收

布局/文本换行仅在尺寸、GUI scale、语言、结构数据或UI状态改变时重算；倒计时只改可见行文字。型号显示名缓存跟随资源重载失效，避免hover每帧重复查自定义资源。UI无逐帧网络发送，也不因鼠标移过车站订阅ETA。

站点命中静态索引按目录revision更新；查询处理局部候选，车辆复用已有视口/车体命中，不再复制一份全图车队。缓存空间有界，不能为每个历史车站保留永不清理的排版。暂停菜单、关闭地图和折叠卡片后的服务端请求/租约释放都计入费用验证。

| 阶段 | 交付/必测 |
| --- | --- |
| U0 宿主桥验证 | Xaero NF/Fabric及旧Forge映射、JM5/6的按下/释放/拖动/滚轮/键盘、渲染层序与暂停。先用小型诊断原型记录事件顺序，不能只构建通过 |

最低视觉矩阵：1920×1080/1280×720及缩小窗口；用实际GUI可用尺寸记录布局，不将分辨率当GUI尺寸。高GUI scale下标题/关闭必可见；默认折叠时ETA请求数为0；展开一站不新增全图车辆成员过滤；快速重试有上限；同场景记录UI布局/命中/绘制耗时、分配和查询次数，与1.5.2比较，不能直接声称更快或零开销。
